# 《begin again》说明文档

一个**离职者本人做给同事们的网页小游戏**：玩家（同事）从锁屏开始，穿越回四年里的同一间办公室，找回四枚记忆碎片，拼出密码，最后收到一张「员工档案」和一封留言。

> 视角先说明白：**作者 = 要走的那个人**（🐘🐏，工号 5147）；**玩家 = 留下来的人**。
> 所以结尾那封信是「我写给你们的」，不是「你们写给我的」。

线上地址：<https://fantasea98.github.io/begin-again/>

---

## 一、主题

**用一个「穿越回过去」的小机关，让同事们把一起共事的四年重新走一遍。**

作者 2023.10.05 入职、2026.10.30 离职，在岗 **1122 天**，工号 **5147**。
故事不直接说「我要走了」，而是让同事当那个「回来找东西的人」：四年被拆成四个房间，每个房间里有一件不起眼的东西，点开就是一段共同经历。

- 情感顺序：**好奇 → 熟悉的疲惫 → 高光时刻 → 告别**
- 首尾呼应：开场是手机锁屏，结尾是一张档案卡；中间发生的一切都「归档」了
- 密码不是彩蛋，是**工号 5147**——四枚碎片上的数字，就是作者留在这里的编号
- 最后一屏从「游戏」交还给「人」：档案卡、红章，以及一封用第一人称写给同事的留言

## 二、玩家旅程（5 屏）

```
锁屏  →  微信群聊（时空乱流）  →  回忆大厅（四个年份）  →  四个关卡  →  终极密码  →  员工档案
 ↑轻触            ↑穿越                    ↑同一间办公室       ↑各拿走一枚碎片      ↑5147       ↑盖章「已离职」
```

| 屏 | 内容 | 设计意图 |
|---|---|---|
| 锁屏 | 黄昏海面、17:00、10月30日星期五、天气与心情卡 | 用 iOS 锁屏的熟悉感做开场；顺带解决浏览器"必须有真手势才能出声"的限制 |
| 群聊 | 微信气泡逐条弹出 → 时空乱流警报 → 内心 OS | 先建立"这是什么群、这是哪一年"的日常感，再打破它 |
| 大厅 | 同一间办公室的四个年份，可点年份标签切换 | 用挂钟时刻和窗外天色暗示年份，靠"找东西"推进 |
| 关卡 | 四个小游戏，各产出一枚碎片 | 每年一种"工作里的真实体验" |
| 终页 | 员工档案卡 + 长信 + 红章「已离职」 | 把四年的痕迹收成一份档案，最后附一封写给同事的留言（落款 🐘🐏） |

## 三、四关的互动设计

每关都是**一种真实的上班体验**，被压成 30 秒内能玩完的小交互。

### 1 · 2023「初来乍到」— 拨号
- 电话簿只给你看 **3 秒**（第二次打开只剩 2 秒），记住组织部那串 8 位号码
- 按完 8 位 → **静 1 秒**（像真的在等线路）→ 回铃音 2.4 秒 → 再静 1 秒 → 判定
- 接通 = DTMF 拨号音 + 三连和弦；输错 = 标准忙音 + 一句打错的俏皮话
- 碎片：**入职碎片 5**

### 2 · 2024「好的，收到」— 敲键盘
- **5 秒**内点满 **30 下**「敲一下键盘」，屏幕里的稿纸随着进度一段段写满
- 时间条由蓝转金（下班的天色）；敲满 → 解锁成就「先进个人最速传说」
- 超时 = 加班，重来
- 碎片：**牛马碎片 1**

### 3 · 2025「像你这样的朋友」— 节拍点击
- 点 **MUSIC!** 开幕，幕布向两侧拉开；共 **8 个动作**
- 收缩圈与虚线框重合的那一小段（约 0.3 秒）内点击 = PERFECT，随机蹦出 PERFECT / BRAVO / 爽词
- MISS = **幕布重新拉上**，回到"点击 MUSIC 开始"的状态，从头再来（不直接判负）
- 碎片：**唱跳碎片 4**

### 4 · 2026「最终任务」— 打包
- 从 **10 件东西**里挑 **3 件**带走（热爱、朋友、回忆、自由、金钱、经验、成就、执行力、创造力、责任感）
- 选中的会贴进手提箱；三件齐了才出现「带走」
- 确认后，三件东西在文案里**一个一个蹦出来**，最后一句是「最后一个碎片缓缓掉落」
- 碎片：**未来碎片 7**

> 四枚碎片的数字连起来 = **5 1 4 7** = 工号。密码页要让玩家自己意识到这件事。

## 四、视听设计

### 视觉
- **主调**：暖棕描边 + 米卡其纸感，像一本手账；不用纯黑、不用大面积深色
- **一屏一个色彩人格**：锁屏是黄昏海面（橙）、2023 米黄、2024 天蓝、2025 深紫舞台、2026 深绿夜幕、终页米白档案纸
- **细节**：贴纸式硬投影、手绘 SVG 场景（房间、行李箱、工牌）、emoji 作为道具而不是图标

### 听觉（全部实时合成，项目里没有任何音频文件）
| 类型 | 例子 |
|---|---|
| 界面反馈 | 按钮轻响、翻页纸张声、选中物品的木琴「叮」 |
| 剧情音效 | 时空乱流的低频撕裂 + 磁带停转；系统警报的高低双音警笛（连响三遍） |
| 节奏伴奏 | 第三关的底鼓 + hi-hat，重拍正好落在判定点 |
| 氛围 BGM | 第四关的 C 大调 3/4 拍音乐盒小曲，淡入 3.6 秒、音量约为音效的 1/10 |

节奏原则：**一屏之内同一个动作只用一种音色**；重要节点（盖章、礼花、碎片入袋）才用"大音"。

## 五、技术实现

### 文件
| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架（手机外框 + 9 个 view 容器） |
| `main.js` | 全部逻辑与文案，**所有可改内容集中在顶部的 `CONFIG`** |
| `style.css` | 样式（约 72KB，按屏分块） |
| `sfx.js` | Web Audio 音效合成器（约 33KB，60+ 个音色函数） |
| `id-photo.svg` | 终页工牌照（描摹图，160KB） |
| `fonts-*.woff2` | 两个子集字体：Playfair（时钟数字）、Great Vibes（begin again） |

### 几个关键点
- **纯原生**：无框架、无构建、无第三方库；改完直接刷新即可
- **进度存档**：`localStorage['beginAgain.progress']`，只存每关是否通关与碎片；失败次数不存档
- **失败兜底**：任一关失败 3 次，弹窗里会出现「😏 我要作弊」，直接跳到成功结算
- **音频解锁**：浏览器要求"一次真手势"才能出声，所以开场做成「轻触锁屏 → 假的面容 ID → 解锁」；拖动不算用户激活，这也是为什么是"轻触"而不是"滑动"
- **断线续命**：切后台、锁屏、来电、插拔耳机之后，`AudioContext` 常被系统挂起。这里挂了四路恢复（回到前台 / bfcache / 焦点回来 / 设备变化）+ 一个 1.2 秒看门狗，自动 resume，不需要玩家重新解锁
- **适配**：手机竖屏占满；桌面自动套上一只手机外框

## 六、想改的话

| 想改 | 去哪 |
|---|---|
| 姓名、工号、部门、起止日期、天数、密码 | `main.js` 顶部 `CONFIG`（`workDays` / `workDates` / `password` / `finalPage`） |
| 最终留言（**作者写给同事们**的信，第一人称） | `CONFIG.finalMessage`，一个字符串一行，加几行都行 |
| 大厅标题、引导语、按钮文案 | `CONFIG` 里的 `hallTitle` / `openingChat.guide` / `collectLabel` 等 |
| 四关的题目（号码、字数、动作、物品） | `CONFIG.levels[]` |
| 配色 | `CONFIG.THEME`（会注入成 CSS 变量）+ `style.css` 里的场景色 |
| 音效 | `sfx.js`，每个音效是一个独立函数，改频率/时长即可 |
| 缓存版本 | 改完记得把 `index.html` 里的 `?v=xxx` 一起改掉，否则手机可能吃旧缓存 |

## 七、已知取舍

- **工牌照 160KB**：是个 SVG 描摹图，首屏就 `preload` 并预热，正常网络下走到终页时已在缓存里；弱网首次进入可能稍慢
- **音量**：只有一个总开关（右上角喇叭），没做音量滑杆；iOS 静音拨杆仍可能静音，锁屏上有提示
- **只有竖屏**：横屏没有专门适配，桌面端是手机外框内的竖屏
- **第三关靠手感**：判定窗口比较宽容，但确实吃网络/性能；卡顿时会更容易 MISS
